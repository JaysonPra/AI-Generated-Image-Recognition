# AI Image Recognition

A full stack ML pipeline to classify whether an image is generated by AI or by Human.

**Core Architecture:** PyTorch, Optuna, MLflow, Scikit-learn, Pandas, FastAPI, Docker

## System Architecture

- **Data Pipeline:** Developed custom Dataset and DataLoader classes with support for image transformations
- **Experiment Tracking:** Implemented Optuna for Bayesian hyperparameter tuning, and MLflow for logging hyperparameters and artifacts
- **Model Registry:** Used Model Aliases(`@champion`) for deploying a single model
- **Deployment:** Developed a multi-container environment using Docker to synchronize FastAPI inference and MLflow tracking server

## Tech Stack
- **Language:** Python 3.13
- **ML Framework:** Scikit-Learn, PyTorch
- **Image Manipulation:** Pillow
- **API Framework:** FastAPI
- **Data Exploration:** Pandas, Seaborn
- **Experiment Tracking:** MLflow
- **Hyperparameter Optimization:** Optuna
- **Containerization:** Docker

## Setup Instructions
### 1. Prerequisites

Install **uv** using the appropriate command for your OS:

**Linux / macOS:**
```bash
curl -LsSf [https://astral.sh/uv/install.sh](https://astral.sh/uv/install.sh) | sh
```

**Windows (PowerShell):**
```powershell
powershell -ExecutionPolicy ByPass -c "irm [https://astral.sh/uv/install.ps1](https://astral.sh/uv/install.ps1) | iex"
```

### 2. Quick Start (Development)

```bash
git clone https://github.com/JaysonPra/AI-Generated-Image-Recognition.git
cd AI-Generated-Image-Recognition

uv sync --extra dev

uv run streamlit run app/app.py
```
The app will be available at http://localhost:8501/

### 3. Automated Setup (Recommended)

**Linux / macOS:**
```bash
chmod +x setup.sh && ./setup.sh
```

**Windows:**
```batch
setup.bat
```
